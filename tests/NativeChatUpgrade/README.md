# NativeChat asset upgrade regression

This console regression links the production NativeChatFileManager and embeds the
asset ZIP generated by the WPF build. It creates a valid 1.0.4 installation with
old client contents, runs the startup update check, and verifies that every new
asset is installed, the old bundle is backed up, and a second startup does nothing.
Settings and paths are test doubles; no application window or user data is used.

Run on Windows with Node.js and the .NET 8 SDK, from the repository root:

```powershell
Push-Location NativeChatClient
npm ci
npm run build
Pop-Location
dotnet build TransparentTwitchChatWPF.sln -c Release
dotnet run --project tests/NativeChatUpgrade
```

Rebuild the assets and WPF project before this test after changing client files.
The generated ZIP is ignored and is never checked in.
